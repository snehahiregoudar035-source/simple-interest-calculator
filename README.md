# Simple Interest Calculator

## About the Project
The Simple Interest Calculator is a basic project that calculates the simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal = Initial amount of money.
- Rate = Annual interest rate (in percentage).
- Time = Time period (in years).

## Example

Input:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Calculation:

SI = (1000 × 5 × 2) / 100
Find Commit changes.
Output:

Simple Interest = 100

Total Amount = 1100
